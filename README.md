# SIH 2026 — Team Submissions

Welcome to the SIH 2026 project submission portal.

## Submit your project

Use the GitHub Issue Form to submit your team details, problem statement, project description, technology stack, repository, presentation, demo video, college, and declaration.

**[🚀 Submit SIH Project](./issues/new/choose)**

## Submission checklist

Before submitting, keep these ready:

- Team name and team leader details
- Contact number
- Complete list of team members
- Problem Statement ID and title
- Theme and category (Software/Hardware)
- Project description
- Technology stack
- GitHub repository link
- PPT / presentation file or an accessible Drive/OneDrive link
- Demo video link
- College / institute name

### PPT upload

If the presentation is too large for a GitHub attachment, upload it to Google Drive or OneDrive and paste an accessible link in the PPT field. Make sure the link can be opened by the reviewers.

### Important

- Submit **one issue per team**.
- Fill every required field accurately.
- Keep your GitHub repository and shared files accessible to the reviewers.
- Do not submit confidential information or passwords.
